# Enterprise Frontend

A responsive React application scaffolded with Vite for the enterprise-application workspace.

## Features

- React 19 application foundation
- Responsive enterprise landing page
- Vite development server with hot module replacement
- Oxlint code quality checks
- Production build support

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

The development server is available at the URL printed by Vite, typically `http://localhost:5173`.

## Project structure

- `src/App.jsx` — application layout and content
- `src/App.css` — responsive application styling
- `src/index.css` — global styles and design tokens
- `vite.config.js` — Vite and React configuration
